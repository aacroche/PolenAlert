# PolenAlert
App Android que muestra los niveles de polen de tu ubicación y avisa a personas alérgicas cuando se supera su umbral.

## Stack
Kotlin 2.4 · Jetpack Compose · MVVM + Clean Architecture · Hilt (KSP) · Retrofit + kotlinx.serialization · Coroutines/Flow

## Datos
[Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) (6 tipos de polen, 4 días de previsión, Europa).
